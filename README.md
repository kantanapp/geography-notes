# Geography Notes 穴埋めアプリ

地理プリント Unit 1.1〜1.3 の空欄に、キーボードで答えを打ち込んで練習するアプリです。

- 空欄をタップして英語で入力（Enter で次の空欄へ）
- 入力を終えた空欄は自動で ○（緑）／×（赤）
- 「Check answers」で今回のけっか：ほめ言葉・星・点数・なおすところ（タップでその空欄へ）
- 問題のすぐ下に **Progress**：ぜんぶの進みぐあい・Unitごとのカード・ごほうびバッジ・グラフ・過去の記録
  （右上の点数をタップすると下へジャンプ。空欄を埋めるたびに その場で更新される）
- 「Show answers」で正解を表示
- 入力と記録はこの端末のブラウザに自動保存
- 画面の表示はすべて英語

## 公開ページ
https://kantanapp.github.io/geography-notes/

スマホのブラウザでこのURLを開けばそのまま使えます（ホーム画面に追加しておくとアプリのように開けます）。

## 使い方
`index.html` をブラウザで開くだけでも動きます。
公開手順・Claude Code での開発手順は [docs/SETUP.md](docs/SETUP.md) を見てください。
